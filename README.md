# موقع شركة ديلتون لخدمات وإدارة المنشآت ش.م.م
### Delton for Services & Facility Management S.A.E - Official Website

موقع تعريفي احترافي متكامل (Landing Page) ثنائي اللغة (عربي / إنجليزي) لشركة **ديلتون لخدمات وإدارة المنشآت ش.م.م**، مبني بالكامل كملفات Static جاهزة للرفع والتشغيل المباشر على استضافات الويب المشتركة مثل **HostGator** و **cPanel** بدون أي حاجة لـ Node.js أو عمليات Build معقدة.

## 🚀 طريقة الرفع على استضافة HostGator (خطوة بخطوة)

### الطريقة الأولى: عبر لوحة تحكم cPanel (File Manager) — الأسرع والأسهل

1. سجل الدخول إلى لوحة تحكم الاستضافة الخاصة بك في HostGator عبر الرابط:
   `https://yourdomain.com:2083` أو من خلال منطقة العميل في HostGator.
2. توجه إلى قسم **Files** واضغط على **File Manager**.
3. افتح المجلد الرئيسي للموقع وهو عادة: `public_html`.
4. (اختياري) إذا كان هناك ملفات افتراضية قديمة مثل `default.html` أو `index.php` خاصة بالاستضافة، قم بحذفها أو نقلها لمجلد احتياطي.
5. اضغط على زر **Upload** في أعلى الصفحة.
6. قم بضغط ملفات الموقع بالكامل في ملف مضغوط واحد باسم `delton-website.zip`، ثم ارفعه عبر صفحة الرفع.
7. بعد اكتمال الرفع (يصل شريط التحميل للون الأخضر 100%)، عد إلى `public_html`، واضغط بالزر الأيمن على `delton-website.zip` ثم اختر **Extract** لفك الضغط.
8. تأكد أن ملف `index.html` موجود مباشرة داخل `public_html` وليس داخل مجلد فرعي متداخل.
9. افتح موقعك في المتصفح: `https://www.delton-eg.com` وستجد الموقع يعمل مباشرة وبسرعة فائقة!

---

### الطريقة الثانية: عبر برنامج FTP (مثل FileZilla أو WinSCP)

1. افتح برنامج FileZilla وسجل الدخول ببيانات الـ FTP الخاصة باستضافتك (Host, Username, Password, Port: 21).
2. في الجزء الأيمن (Remote Site)، ادخل إلى مجلد `public_html`.
3. في الجزء الأيسر (Local Site)، حدد جميع ملفات ومجلدات هذا المشروع (`index.html`، مجلد `assets`، مجلد `admin`، ملفات الـ PDF، إلخ).
4. اسحب الملفات وافلتها داخل `public_html`.
5. انتظر حتى تنتهي جميع عمليات النقل (Transfers).

## ⚙️ إعداد لوحة تحكم السلايدر على HostGator

المشروع مزود بـ **حلين مدمجين** للتحكم بالسلايدر:

### 1. الحل الأساسي المباشر عبر PHP (`admin/index.php`):
- يتيح لك تعديل نصوص وصور السلايدر بالعربية والإنجليزية مباشرة من المتصفح وحفظها بنقرة زر بدون أي برامج خارجية وبدون قاعدة بيانات.
- **رابط اللوحة**: `https://www.delton-eg.com/admin/index.php`
- **كلمة المرور الافتراضية**: `delton2026`
  > يمكنك تغيير كلمة المرور في أي وقت بفتح ملف `admin/index.php` وتعديل السطر رقم 10:
  > `$ADMIN_PIN = "كلمة_المرور_الجديدة";`
- **ملاحظة الأذونات (Permissions)**:
  لكي يتمكن سيرفر PHP من حفظ التعديلات في ملف `slider.json`، تأكد عبر File Manager من أن تصريح ملف `admin/slider.json` هو `664` أو `666`، وتصريح مجلد `assets/images/hero/` هو `755` أو `775`.

### 2. الحل البديل الثابت (`admin/index.html`):
- إذا كنت تفضل عدم استخدام PHP، يمكنك فتح `admin/index.html` في متصفحك، وإجراء التعديلات، ثم الضغط على **"تحميل ملف slider.json المحدث"**، ورفعه يدويًا عبر cPanel إلى مجلد `admin/`.
